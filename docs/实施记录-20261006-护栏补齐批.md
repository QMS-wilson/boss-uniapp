## 踩坑记录

- `python`/`python3` 在这台机器是 WindowsApps 存根（exit 49、零输出），**一律用 `py -3`**；
  `deploy.py` 依赖的 `scp` 模块 2026-10-06 已 `py -3 -m pip install scp` 补上。
- 写门时两条判据的教训：`page.value--` 前面隔着注释行（正则要 `[\s\S]{0,200}?` 非贪婪，
  不能 `\s*\n\s*`）；`!r.confirm || busy.value` 不匹配 `if (busy.value) return`
  （入口守卫与回调守卫要分开数）。
