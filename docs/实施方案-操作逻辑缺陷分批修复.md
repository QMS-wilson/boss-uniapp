## B7 单价 0 元的明细 → 赠品指引 + 强制开关（2026-10-05）

需求原话：「开单时单价为0的明细，要指引客户是否开启赠品。做成配置，单价为0产品是否强制赠品。」

- **什么时候问**：单价输入框 **blur**（离开那一格）才问，打字途中不问；空着不问（空单价是"还没填"，
  归提交前的「单价要填」那条管）。一行只问一次（`_zeroAsked`，不进退出挽留的判脏快照）。
- **三个按钮的语义**：记成赠品 = `gift=true` + 重算这一行；「就按 0 元」= 承认这笔 0 元成交，什么都不改；
  「先不动」= 关掉框留在原处（单价仍是 0，下次离开输入框会再问）。**不替人默认勾赠品**。
- **配置**：`cfg:billZeroGift`，在 系统配置 → 开单明细，**默认关**（判法 `=== true`，与同一张卡上
  `billExitAsk`/`billStockWarn` 两个"默认开"的 `!== false` 相反）。默认关的理由：0 元单价在这行账里
  是合法记法（样品、试机、售后补发、以物抵债），一上来挡人等于替客户改记账习惯。
- **开关只改两件事**：① 框里第二个按钮从「就按 0 元」换成「返回改单价」（不给按 0 元这条出口）；
  ② 提交前多一条拦截 `单价 0 元的行要记成赠品，或把单价改成实际成交价`，兜"问了没答 / 先不动 /
  勾了赠品又取消"三个漏口。件数、合计、折合、库存扣减一概不因这个开关变。
- **只管销售开单**：采购没有赠品概念，`purchase/edit.vue` 不接这条。
